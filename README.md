# Veterinary Appointment Management Web App

This project is a simple web-based appointment management system developed as part of a Software Engineering workshop.
It allows clients to book appointments for veterinary services through an intuitive form, while providing an admin view to manage and visualize upcoming reservations.

The application is built using HTML, CSS, and JavaScript, with LocalStorage used to simulate backend data persistence.
Core business rules such as working hours validation, weekend blocking, and service overlap prevention are handled through a dedicated logic layer.

The project follows a modular structure and focuses on usability, responsive design, and clean separation of responsibilities.
